# Jinsa's archived development iterations

These folders preserve two earlier versions of Jinsa Bai's User input mechanic for comparison. Each folder contains the complete, unchanged file tree from its original commit, including the code, libraries, preview and tests.

| Snapshot | Original commit | Development stage |
| --- | --- | --- |
| [Iteration 07](iteration-07/) | [a0bb4e5](https://github.com/bjsss400-dot/9103-AAAAA1/commit/a0bb4e58bfa7da1b946a62a6c43741afec93188a) | Standalone canvas-only prototype with the 14 course techniques and upward colour filling. Clicking cycles colours in the independently designed 17-cell test layout. |
| [Iteration 11](iteration-11/) | [9931144](https://github.com/bjsss400-dot/9103-AAAAA1/commit/993114409791e70bd38b7103f29fb2ad63aa89b2) | Integrated 20-cell team canvas with seven swatches, keys 1-7, eight shade levels, colour changes, white erasing, undo/redo and continuous filling. |

## Open a historical version

- Iteration 07: download [jinsa-square-only.html](iteration-07/jinsa-square-only.html) and open the downloaded file in a browser.
- Iteration 11: download [jinsa-team-grid.html](iteration-11/jinsa-team-grid.html) and open the downloaded file in a browser. Wait for the 14 strokes to finish before choosing a colour and painting.

Both preview files contain their own p5.js library and project scripts. You can also download the repository and open either snapshot's `index.html`.

## Current version

The current project remains at the repository root and in `9103 creative coding/`. Open [the latest seven-colour preview](../jinsa-colour-palette-v2.html) for the current version.

The numbered folders refer to the original development commits. This archive preserves those stages and their existing history.
